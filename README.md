# 2026 国赛 C 题《微网与外部电网电力调控策略的优化模型研究》解题仓库

本文针对 2026 年高教社杯全国大学生数学建模竞赛 **C 题**，把小区负载、光伏发电与储能设备之间的能量协调统一建模为**线性规划（LP）**，并用**滚动时域优化**处理光伏预报不确定与实时波动电价。仓库内含：

- **LaTeX 参赛论文**（主交付物，目录 `latex/`，32 个分节源文件 + 国赛模板 + 思源宋体字库）；
- **Python 求解程序**（`latex/求解/`，四问各一脚本 + 共用建模模块 + 稳健性检验）；
- **结果数据与插图**（5 个结果 xlsx、26 张中文标注图）；
- **Word 版论文**（`2026数学建模国赛论文.docx`，由 `make_paper.py` 生成，作为辅助对比版本）。

## 一、四个问题的方法与结果

| 问题 | 场景 | 方法 | 关键结果（论文口径） |
|---|---|---|---|
| Q1 | 典型日，电价/负荷固定，光伏用给定预测 | 单日 LP，储能首尾储电量相等（0:00 = 24:00 = 6000 kWh） | 购电量 **59482.70 kWh**，购电费 **35126.95 元** |
| Q2 | 全年 365 天（1 月为预热期），确定性数据，可按 5 倍电价紧急购电 | 逐日滚动 LP：日末储电量传给次日 | 按附件 5 口径统计 2/1—12/31（**334 天**）合计 **12254765.72 元**，紧急购电 0 |
| Q3 | 小时级光伏预报在 0:00/6:00/12:00/18:00 更新，计划可调整 | 滚动时域（MPC）+ 分段违约/超额费用线性化（下调 0.5 倍、上调 1.5 倍电价） | 含调整总费用 **14337999.15 元**，较只执行 0:00 计划（14782072.51 元）省 **444073.36 元（3.004%）**；紧急购电 416613.13 kWh |
| Q4 | 电价换成附件 4 的逐间隔实时波动电价 | 模型不变，替换价格序列重算 Q2、Q3 两类 | Q2 情形 **12841054.36 元**；Q3 情形 **14956526.18 元** |

一句话结论：**"低谷充电、高峰放电"的套利策略是关键，"白天按新预报滚动修正计划"能在预报偏差下继续省钱（约 3%），但收益对预报质量敏感——这就是它的使用边界。**

## 三、论文主目录 `latex/` 怎么用

### 3.1 编译出 PDF

需要 **XeLaTeX**（`format.cls` 用 `xeCJK` + `fontspec` 加载 `fonts/` 下的思源宋体）。命令：

```bash
cd latex
xelatex -interaction=nonstopmode 论文.tex    # 第 1 遍：生成目录与交叉引用
xelatex -interaction=nonstopmode 论文.tex    # 第 2 遍：交叉引用收敛
```

或一步到位（VS Code 里用的就是这个）：

```bash
cd latex && latexmk -xelatex -interaction=nonstopmode 论文.tex
```

`论文.tex` 用 `\input{0.摘要}` 这种**带扩展名**的写法按序引入 32 个分节文件：

```
0.摘要 → 1.引言 → 2.总体分析 → 3.模型假设 → 4.符号说明
→ 5.模型的建立与求解（5.1~5.4 各含 具体分析/模型准备/模型建立/模型求解 四段式）
→ 6.模型检验 → 7.模型评价 → 8.模型改进推广 → 9.AI说明 → 10.参考文献 → 11.附录
```

第 5 章的四段式（**具体分析 → 模型准备 → 模型建立 → 模型求解**）是韩中庚《数学建模竞赛论文的写作方法》里反复强调的组织方式：先讲清这一问到底要求什么、已知什么、准备怎么做，再给模型，最后给结果。四问都严格按这个骨架写。

### 3.2 `fonts/` 是什么

思源宋体（Source Han Serif CN）的两个字重：

| 文件 | 大小 |
|---|---|
| `SourceHanSerifCN-Regular.otf` | 11.3 MB |
| `SourceHanSerifCN-Bold.otf` | 11.8 MB |

`format.cls` 里以相对路径 `./fonts/` 引用它们。**必须保留**，删掉就编译不出中文。

### 3.3 摘要（`0.摘要.tex`）

摘要按"背景与目标 → 四问分述 → 创新点与价值"三段组织：四问各段均以加粗的 `针对问题X` 起头，逐段交代**问题定位、建模方法、关键结果数字**；每段的数字与正文、`latex/求解/` 的实测输出完全一致（可回代核对）。末段以"**其一 / 其二 / 其三**"显式列出三条创新点（LP 保全局最优、逐日滚动时域分解、上境变量线性化分段费用），并收束到"结论可核验、可为微网经济调度提供决策参考"——对应写作方法里"摘要须交代方法与创新点、力求可核验"的要求。

`\keywords{}` 五词：微网；储能调度；线性规划；滚动时域优化；光伏预报。

## 四、求解程序

### 4.1 运行

```bash
# 在仓库根目录下执行
python "latex/求解/问题一/问题一.py"
python "latex/求解/问题二/问题二.py"
python "latex/求解/问题三/问题三.py"
python "latex/求解/问题四/问题四.py"
python "latex/求解/稳健性检验.py"
```

依赖：`pip install pandas numpy scipy openpyxl matplotlib`

### 4.2 数据是怎么找到的（不写死路径）

`latex/求解/_common.py` 的 `_find_data_dir()` 和 `latex/求解/_models.py` 的 `_data_dir()` 会从脚本所在目录出发，逐级向上、以及向上一级目录的子目录里搜索含 `附件1.xlsx` 的 `附件/` 或 `数据/` 目录，取第一个命中者。当前仓库里命中 `C题/附件/`。这样把 `latex/` 移到仓库根、或换个机器，程序都不用改。

### 4.3 输出

| 脚本 | 写到哪 |
|---|---|
| `问题一.py` | `求解/问题一/结果/`、`求解/结果/result1.xlsx`、`求解/预处理数据.csv`（供后续三问共用） |
| `问题二/三/四.py` | 各自 `问题X/结果/` 与 `求解/结果/`；图写到各自 `问题X/图片/` |
| `稳健性检验.py` | `求解/图片/图6-1_稳健性检验.png`，其余结果打印到终端 |

四个问题的图共 **26 张**：问题一 6、问题二 6、问题三 7、问题四 6、稳健性检验 1。

### 4.4 模型是怎么验的

- **约束残差**：解出来后回代所有约束，功率平衡残差 1.36×10⁻¹²，容量与功率越界 0 次。
- **算法交叉验证**：Q1 用动态规划（ΔE = 20 kWh 网格）独立复算，35222.69 元 vs LP 35126.95 元，偏差 +0.27%，说明 LP 结果不是求解器假象。
- **数据摄动**：对负载与光伏加 σ=5%、σ=10% 高斯噪声各重算多次，均值偏差都在 0.6% 以内。
- **无储能对照**：去掉储能后 Q1 涨到 48052.05 元、Q2 涨到 16407319.63 元，反证储能套利的贡献（分别省 26.90%、25.31%）。
- **口径对照**：把"预报展开口径"从线性插值换成阶梯保持，总费用从 14337999.15 元变成 17948773.82 元——口径本身的影响比参数扰动大得多，所以论文单独交代了这条。

## 五、Word 版论文（辅助对比）

`2026数学建模国赛论文.docx` 是同一道题、同一套模型的**单文档 Word 排版版本**，与 `latex/` 下的多文件版同题不同编排，便于对照阅读与投稿备用。

- **改 Word 版 = 改脚本后重跑**：`python make_paper.py` 会重新生成 `2026数学建模国赛论文.docx`（含程序附录）。不要手动编辑 docx，否则下次生成会被覆盖。
- 配套的参考文献文档：`python make_refs.py` → `C题/thesis/参考文献.docx`。
- 它对应的求解程序在 `C题/code/`（`lp_core.py` + `q1~q4.py` + `q5_sensitivity.py` + `sens_r1r3.py` + `q4_corr.py`），与 `latex/求解/` 是**两套独立实现**，建模思路一致但紧急购电的核算细节不同，因此个别数字不同（例如该套算出的 Q3 为 17000834.39 元，与本仓库 `latex/` 版的 14337999.15 元不可混用）。**论文里引用数字请以所用版本为准，不要跨版本混引。**

```bash
# Word 版复现
python "C题/code/q1.py" && python "C题/code/q2.py" && python "C题/code/q3.py" && python "C题/code/q4.py"
python "C题/code/q5_sensitivity.py"   # 容量/效率/预报偏差灵敏度
python "C题/code/sens_r1r3.py"        # Q1、Q3 关键量复算
python "C题/code/q4_corr.py"          # 电价 vs 购电量/购电费相关系数
python make_paper.py && python make_refs.py
```
