## 5. 四个问题的方法与结果

四个问题层层递进：问题一是**单日确定性**调度；问题二因当天负载与光伏尚未发生而引入**信息不完备**，改为全年两阶段随机规划；问题三在问题二基础上增加**日内 0:00/6:00/12:00/18:00 四次光伏预报与计划调整**（滚动时域）；问题四把固定的分时电价换成附件四的**逐 10 分钟波动电价**，把问题二、问题三两套模型重算一遍。

### 5.1 问题一：单日确定性线性规划

**方法.** 把一天离散为 144 个 10 分钟时段，以全天购电费最小为目标：

```
min Z = Σ_k  g_k · p_k · Δt
```

决策变量为各时段的购电功率 `g_k`、储能充电 `c_k`、放电 `d_k` 与储电量 `E_k`，共 577 个连续变量。约束包括功率平衡 `g_k + S_k + d_k − c_k ≥ L_k`（允许弃光）、储能递推 `E_{k+1} = E_k + η·c_k·Δt − d_k·Δt/η`、储电量上下限 `[1200, 10800]` kWh、充放电功率不超过 5000 kW、以及日循环条件 `E_0 = E_144 = 6000` kWh，取 `η = 0.9`。模型为纯线性规划，由 Python 线性规划求解器直接求解（`code/问题一.py`）。

**结果.** 全天购电量 **59482.70 kWh**，购电费 **35126.95 元**（表 1-1）。低谷 0:00—4:00 充电 4500.00 kWh、不放电；高峰 16:00—20:00 放电 5780.13 kWh、20:00—24:00 充电 5333.33 kWh；10:00、14:00、20:00 三个高价时段购电量降为 0，12:00 / 16:00 / 18:00 时段分别购电 480.41 / 445.43 / 531.89 kWh（表 1-2）。储能起止储电量均为 6000.00 kWh，满足日循环。**结论：低价充电、高价放电是费用下降的主因。**

### 5.2 问题二：计及紧急购电的两阶段随机规划（全年 334 天）

**方法.** 全年逐日求解，遵循「先预测 → 再定计划 → 后结算」的两阶段结构。预测采用「日水平 × 日内形状」的乘积式分解：负载按工作日/周末分别取最近 8 日的形状与 2 日加权水平，光伏取 4 日形状与 4 日水平。用残差经验分位数标定三档乘性因子，负载 `λ^L = (0.9526, 0.9986, 1.0435)`、光伏 `λ^S = (0.9073, 1.0139, 1.1301)`，交叉组合成 9 个情景，权重 `(0.2, 0.6, 0.2)`。目标为**计划购电费 + 5 倍电价下期望紧急购电费**，缺口约束用「下界 + 正系数」线性化，仍为不含整数变量的线性规划；储电量跨日传递 `E_{d+1,0} = E_{d,144}`，不设终端约束。单日 1873 个变量，全年 334 次求解约 10.6 s。

**结果（2.1—12.31 共 334 天）.** 计划购电 **21833065.92 kWh**、计划购电费 **13325494.59 元**；紧急购电 **282910.68 kWh**、紧急购电费 **1057398.40 元**；总购电费 **14382892.99 元**，日均约 **43062.55 元**，紧急电量仅占计划的 1.30%。334 天中有 333 天出现紧急购电，合计 8609/48096 个时段（17.90%），最大功率 2143.48 kW、单日最大 12595.53 kWh；全年弃电 2881875.41 kWh。预测精度：负载 MAE 130.24 kW、RMSE 179.00 kW、相对误差标准差 4.50%；光伏 MAE 150.94 kW、RMSE 305.54 kW、相对误差标准差 9.95%。

四个指定日的全天购电量 / 购电费（表 2-1）：3.20 → **68462.51 kWh / 41502.92 元**；6.21 → **34663.14 / 19596.21**；9.23 → **72005.67 / 44887.63**；12.21 → **98496.73 / 63507.75**。四日 0:00 与 24:00 的储电量均回到 **1200.00 kWh**（表 2-2），16:00—24:00 放电合计均为 8640 kWh，恰为 `0.9 × (10800 − 1200)`；四日紧急购电合计 1400.66 / 424.89 / 583.54 / 830.33 kWh，最长单段 608.79 kWh（表 2-3）。

### 5.3 问题三：含违约惩罚的滚动时域优化

**方法.** 先在 0:00 用问题二模型解出一份全天计划；再在 6:00、12:00、18:00 三个预报时点，依据更新后的光伏预报求解调整子问题。调整后的费用按「少买不加价、多买 0.5 倍、少买 1.5 倍」分段计价：

```
C_k = [ min(g^p_k, g^a_k) + 0.5·max(g^p_k − g^a_k, 0) + 1.5·max(g^a_k − g^p_k, 0) ] · p_k · Δt
```

该分段函数用上境变量 `w_k` 的两条约束线性化（斜率 0.5 与 1.5 两段）；子问题的初始储电量取前一决策执行到该时点的实际值，紧急购电按实际缺口 `δ_k = max{L_k − (g^a_k + S^r_k + d^a_k − c^a_k), 0}` 以 5 倍电价结算。共四个顺序线性规划，整体思想与模型预测控制（MPC）的滚动时域一致。

**结果.** 含调整的总费用 **14337999.15 元**，若只按 0:00 计划执行则需 **14782072.51 元**，**节省 444073.36 元、降幅约 3.00%**。边际贡献：6:00 调整为 −3.74 万元（略有增加）、12:00 调整为 46.15 万元、18:00 调整为 2.00 万元。把预报加密到 3 小时 / 1 小时仅再省 5.12 万 / 0.05 万元，而把 6/12/18 三点的预报整体替换为完全预见可再降 171.33 万元 —— 可见**继续降低成本应优先提高预报精度，而非增加预报时点**。四个指定日的全天购电量（表 3-1）：计划 **67748.70 / 32640.60 / 68433.20 / 93633.20** kWh，调整后 **63217.60 / 33140.10 / 65716.30 / 93783.50** kWh，对应紧急购电费 **12856.00 / 2294.00 / 5600.00 / 2875.00** 元；四日 0:00 与 24:00 储电量均为 1200.00 kWh（表 3-2）。需说明的是，该策略在**期望意义上**有效：334 天中有 155 天调整后费用反高于基准，最差（9.29）多支出 9676.94 元。

### 5.4 问题四：波动电价下的重算

**方法.** 模型结构与问题二、问题三完全相同，仅把固定的分时电价 `p_k` 替换为附件四给出的逐 10 分钟波动电价 `p_{d,k}`，分段违约费用与紧急购电核算中的电价也逐项替换，模型仍为线性规划（`code/问题四.py`，输出 `result4-2.xlsx`、`result4-3.xlsx`）。

**结果.** 问题二口径：计划购电费 **13895479.01 元**，紧急购电 304292.65 kWh、紧急购电费 1181652.65 元，合计 **15077131.66 元**。问题三口径：总费用 **14956526.18 元**，较问题二口径**节省 120605.48 元（约 0.80%）**。四个典型日（表 4-1、表 4-2）：问题二全天购电费 47694.05 / 18367.12 / 49038.12 / 78033.40 元，问题三降至 41997.87 / 15620.14 / 44112.85 / 69824.09 元，问题三含紧急购电的总费用为 54192.97 / 17963.88 / 49152.77 / 75009.33 元。**在波动电价下，日内调整带来的节省率由固定电价时的 3.00% 降至 0.80%。**

- AI 提供 3 种建模思路，本队选择第 2 种并改进，独立推导验证、查文献确认可行性。
