## 二、模型与方法

将每天离散为 144 个 10 分钟时段（Δt = 1/6 h），以各时段购电量、储能充/放电量为决策变量，构建**线性规划（LP）**模型，用 `scipy.optimize.linprog`（HiGHS 求解器）求解：

- **功率平衡**：购电 + 光伏出力 + 放电 ≥ 负荷 + 充电（允许弃光）
- **储能动态**：SOC(t+1) = SOC(t) + 0.9·充电 − 放电/0.9，SOC ∈ [1200, 10800] kWh
- **充放电功率**：变流器上限 5000 kW，即每时段 ≤ 833.33 kWh

四问层层递进：

| 问题 | 场景 | 方法 |
|---|---|---|
| Q1 | 典型日，光伏/负荷/电价已知 | 单日循环 LP（SOC 首尾闭合） |
| Q2 | 全年 334 天，数据确定 | 日际滚动 LP，SOC 跨天传递，含 5 倍电价紧急购电惩罚 |
| Q3 | 光伏存在预报误差 | 滚动时域（MPC）：0:00 计划 + 白天多次重预报调整，含上调/下调罚则 |
| Q4 | 电价为实时波动价格 | 替换电价序列重算 Q2/Q3，量化电价不确定性的影响 |

## 三、主要结果

- **Q1（典型日）**：全天购电 59482.70 kWh，购电费 **35118.60 元**，SOC 首末均为 8550 kWh。
- **Q2（334 天，理想情形）**：总购电费 **12,254,765.72 元**，紧急购电量为 0。
- **Q3（光伏不确定，滚动调整）**：总电费 **17,000,834.39 元**，较"仅 0:00 计划"对照组（17,400,028.28 元）节省 399,193.90 元（**2.29%**）。
- **Q4（实时波动电价）**：Q2 情形总电费升至 **12,841,054.36 元**（+4.78%）；Q3 情形升至 **17,742,495.98 元**（+4.36%），滚动调整仍较对照组节省 2.16%。

结论：滚动时域调整机制在光伏不确定与电价波动下均能稳定降低购电成本，验证了模型的鲁棒性。

## 四、运行方法

环境：Python 3.10，依赖 `pandas numpy scipy openpyxl matplotlib seaborn python-docx`。

```bash
# 1) 计算（在 C题/code/ 下，依次运行；均可在 1 分钟内完成）
cd C题/code
python q1.py   # → C题/result1.xlsx（约几秒）
python q2.py   # → C题/result2.xlsx + q2_log.txt（约几秒）
python q3.py   # → C题/result3.xlsx + q3_log.txt（约 30 秒）
python q4.py   # → C题/result4-2.xlsx / result4-3.xlsx + q4_log.txt（约 1 分钟）

# 2) 绘图（在 C题/pic/ 下，重新生成 12 张 png）
cd ../pic
python qic1.py && python qic2.py && python qic3.py && python qic4.py

# 3) 重新生成论文与参考文献文档（在仓库根目录）
cd ../..
python make_paper.py   # → 2026数学建模国赛论文.docx（含全部代码附录）
python make_refs.py    # → C题/thesis/参考文献.docx
```

说明：所有计算脚本均使用确定性 LP，无机器学习/深度学习等大耗时环节，无需云计算，本地几分钟内可全部复现。结果 xlsx 会同时写入 `C题/` 与提交模板目录 `C题/附件/附件5/`（原始模板已备份于 `附件5/templates_bak/`）。
