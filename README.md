## 模型与方法

将每天离散为 144 个 10 分钟时段（Δt = 1/6 h），以各时段购电量、储能充/放电量为决策变量，构建线性规划模型，使用 `scipy.optimize.linprog`（HiGHS 求解器）求解：

- **功率平衡**：购电 + 光伏出力 + 放电 ≥ 负荷 + 充电（允许弃光）
- **储能动态**：SOC(t+1) = SOC(t) + 0.9·充电 − 放电/0.9，SOC ∈ [1200, 10800] kWh（电池容量 12000 kWh 的 10%–90%）
- **充放电功率**：变流器上限 5000 kW，即每时段 ≤ 833.33 kWh
- **问题一**：典型日优化，附加日循环约束 SOC(24:00) = SOC(0:00)，目标为全天购电费最小
- **问题二**：全年逐日滚动优化，SOC 跨天连续传递（2025-01-01 初始 SOC = 6000 kWh），目标含 5 倍电价的紧急购电惩罚项
