## 一、我做了什么（四个问题层层递进）

把每一天切成 **144 个 10 分钟时段**（Δt = 1/6 小时），对每个时段做三个决定：从外网买多少电、给储能充多少电、让储能放多少电。目标只有一个：**购电总费用最小**，同时满足"买电 + 光伏 + 放电 ≥ 负荷 + 充电"的功率平衡，以及储能不能充爆、不能放空的限制。核心是一个**线性规划（LP）模型**，用 Python 的 `scipy.optimize.linprog`（HiGHS 求解器）精确求解。

| 问题 | 场景 | 我用什么方法 | 关键结果 |
|---|---|---|---|
| Q1 | 典型一天，电价/负荷相同，光伏给一天的预测 | 单日循环 LP（储电量首尾相等） | 购电费 **35,126.95 元** |
| Q2 | 全年 334 天，数据都是确定的，允许 5 倍电价"紧急购电" | 日际滚动 LP：每天解一个 LP，把当天结束时的储电量传给第二天 | 总购电费 **12,254,765.72 元**，紧急购电 0 |
| Q3 | 光伏出力有预报误差，白天多次更新预报，允许买电计划改三次 | 滚动时域（MPC）：0 点订计划，6/12/18 点按新预报重算并锁定调整量 | 总电费 **17,000,834.39 元**，比"不调整"省 **399,193.90 元（2.29%）** |
| Q4 | 电价换成附件 4 的实时波动电价 | 模型不变，只把价格序列换掉重算 Q2、Q3 | Q2 → **12,841,054.36 元**；Q3 → **17,742,495.98 元**，滚动调整仍省 2.16% |

一句话结论：**"低谷充电、高峰放电"的套利策略 + "白天滚动调整计划"的机制，在光伏不确定和电价波动下都能稳定省钱。**

## 三、核心结论速览

- **Q1（典型日）**：全天购电 59,482.70 kWh，购电费 **35,126.95 元**；储电量在 0:00 与 24:00 两端都回到 **6,000 kWh**（首尾相等，满足循环约束）。
- **Q2（全年理想情形）**：总购电费 **12,254,765.72 元**；因为计划买电没有功率上限，5 倍电价的紧急购电一次都没用上（恒为 0）。
- **Q3（光伏不确定）**：滚动调整后总电费 **17,000,834.39 元**，比"只用 0 点预报、白天不调整"的对照组（17,400,028.28 元）**省 399,193.90 元（2.29%）**。
- **Q4（实时波动电价）**：Q2 情形涨到 **12,841,054.36 元**（+4.78%）；Q3 情形涨到 **17,742,495.98 元**（+4.36%），但滚动调整依然比对照组省 2.16%。
- **灵敏度**：电池容量 ±10% 时费用只变约 ±2%；充放电效率 0.85 / 0.95 时费用变 +4.20% / −3.87%，都小于 5% 的常用稳健性门槛——模型对参数是稳的。预报偏差被整体放大 20% 时滚动收益会转负，所以"先做偏差校正再滚动"是它的使用边界。
- **相关分析（8.3 节）**：日均电价与日购电量、日购电费的相关系数分别约 **+0.975 / +0.978**，"电价高 → 买电多"的直觉其实被"峰段负荷也高"共同解释，属于对结果的稳健性旁证（复算见 `C题/code/q4_corr.py`，逐项对照见 `结果/q4_corr_log.txt`）。

## 五、模型方法一句话解释（给队友 / 自己备忘）

- **线性规划（LP）**：目标和约束都是线性的优化问题，能保证找到全局最优解，不是"大概算一下"的启发式。→ 对应题目里"购电、充放电怎么安排最省钱"。
- **SOC 跨天传递**：Q2 把一年拆成 334 个小 LP，每天结束的储电量传给下一天，计算量随天数线性增长，不会爆炸。→ 对应题目里"储电量要连续、不能凭空出现"。
- **模型预测控制（MPC / 滚动时域）**：Q3 白天拿到更新的光伏预报，就重新求解"剩下还没发生的时段"，把计划往前滚动修正。→ 对应题目里"计划允许改三次"。
- **相关分析（Pearson 相关系数）**：8.3 节用日尺度数据算相关系数，判断"电价—购电量"之间的联系，是对结果的旁证而非新模型。→ 对应论文里"结果的稳健性讨论"。
- **灵敏度分析**：把电池容量、充放电效率、预报偏差这几个参数来回 ±10% ~ ±20% 扰动，看结果变多少，判断结论稳不稳。→ 对应论文里"模型的稳健性"。

我**没有**生搬硬套 TOPSIS、灰色预测、神经网络这类方法——本题本质是确定性优化问题，LP + 滚动 + 灵敏度 + 一次相关分析就是最贴切、最不牵强的组合。
