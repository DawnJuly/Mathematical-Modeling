# 2026 国赛 C 题《微网与外部电网电力调控策略的优化模型研究》解题仓库

本仓库针对 2026 年高教社杯全国大学生数学建模竞赛 **C 题**，把小区负载、光伏发电与储能设备之间的能量协调统一建模为**线性规划（LP）**，并在预报不确定下采用**"先预测、再决策、后结算"的三段式滚动框架**：每天 0:00 当天负荷与光伏均未知，先用历史数据建立预测模型生成日曲线，再在紧急电价 5 倍的代价下确定计划购电量，最后按实际偏差结算并逐日滚动传递储电量。仓库同时保存了赛题原文、原始附件、两套独立求解程序、求解结果、绘图脚本，以及历年国赛优秀论文的学习资料。

## 一、四个问题的方法与结果

| 问题 | 场景 | 方法 | 关键结果（论文口径） |
|---|---|---|---|
| Q1 | 典型日，电价/负荷固定，光伏用给定预测 | 单日 LP，储能首尾储电量相等（0:00 = 24:00 = 6000 kWh） | 购电量 **59482.70 kWh**，购电费 **35126.95 元** |
| Q2 | 全年 365 天（1 月为预测模型的历史训练期），当天负荷/光伏 0:00 未知，可按 5 倍电价紧急购电 | **三段式**：0:00 用历史数据滚动预测当日负荷/光伏 → 在预报不确定下按 5 倍紧急电价定计划购电量 → 实际运行按偏差结算；日末储电量传给次日 | 按附件 5 口径统计 2/1—12/31（**334 天**）：计划 21833065.92 kWh（13325494.59 元）+ 紧急 282910.68 kWh（1057398.40 元）= 合计 **14382892.99 元**，日均 43062.55 元；紧急电量占计划电量 1.30%，334 天中 333 天出现紧急购电 |
| Q3 | 小时级光伏预报在 0:00/6:00/12:00/18:00 更新，计划可调整 | 滚动时域（MPC）+ 分段违约/超额费用线性化（下调 0.5 倍、上调 1.5 倍电价） | 含调整总费用 **14337999.15 元**，较只执行 0:00 计划（14782072.51 元）省 **444073.36 元（3.00%）**；紧急购电 416613.13 kWh |
| Q4 | 电价换成附件 4 的逐间隔实时波动电价 | 模型不变，替换价格序列重算 Q2、Q3 两类 | Q2 情形 **15077131.66 元**（计划 13895479.01 + 紧急 1181652.65）；Q3 情形 **14956526.18 元** |

一句话结论：**"低谷充电、高峰放电"的套利策略是关键，"白天按新预报滚动修正计划"能在预报偏差下继续省钱（约 0.8%），但收益对预报质量敏感；Q2 的三段式则说明预报偏差必然转化为紧急购电——这就是预测不确定性的真实代价。**

四个问题都在 `latex/` 论文中按"具体分析 → 模型准备 → 模型建立 → 模型求解"的四段式写作，数字与 `latex/求解/` 的输出一一对应。

## 三、论文主目录 `latex/` 怎么用

### 3.1 编译出 PDF

需要 **XeLaTeX**（`format.cls` 用 `xeCJK` + `fontspec` 加载 `fonts/` 下的思源宋体）。**必须在 `latex/` 目录内编译**，因为 `11.附录.tex` 用相对路径 `求解/...` 通过 `\lstinputlisting` 内嵌全部程序源码：

```bash
cd latex
xelatex -interaction=nonstopmode 论文.tex    # 第 1 遍：生成目录与交叉引用
xelatex -interaction=nonstopmode 论文.tex    # 第 2 遍：交叉引用收敛
```

或一步到位（VS Code LaTeX Workshop 用的就是这个）：

```bash
cd latex && latexmk -xelatex -interaction=nonstopmode 论文.tex
```

`论文.tex` 用 `\input{0.摘要.tex}` 这种**带扩展名**的写法按序引入 33 个分节文件：

```
0.摘要 → 1.引言 → 2.总体分析 → 3.模型假设 → 4.符号说明
→ 5.模型的建立与求解（\input 5.1.问题一 ~ 5.4.问题四，
                      每问再 \input 其 .1具体分析/.2模型准备/.3模型建立/.4模型求解 四段）
→ 6.模型检验 → 7.模型评价 → 8.模型改进推广 → 12.结论
→ 9.AI说明 → 10.参考文献 → 11.附录
```

其中 `9.AI说明.tex`、`10.参考文献.tex`、`11.附录.tex` 分别用 `\section*{}` 与 `thebibliography` 排版，不占正文章号，因此 `12.结论.tex` 紧随第 8 章自动编为**第九章 结论**（正文含 9 个编号章）。

第 5 章的四段式（**具体分析 → 模型准备 → 模型建立 → 模型求解**）是韩中庚《数学建模竞赛论文的写作方法》里反复强调的组织方式：先讲清这一问到底要求什么、已知什么、准备怎么做，再给模型，最后给结果。四问都严格按这个骨架写；问题二、四的"模型建立"一节里还额外交代了三段式（预测—决策—结算）的接口与不确定性来源。

**第 1 章引言只设两个小节**：`1.1 问题背景` 与 `1.2 本文技术路线`。**不设独立的"问题重述"和"国内外研究现状"小节**——2021/2023/2024 三年 12 篇优秀论文的首章一律是"问题重述"下的背景 + 重述两小节，没有一篇单列文献综述；同时问题重述与摘要高度重复，单列会让读者读两遍同样的内容。研究现状以一句归纳（"预测—调度范式、储能峰谷套利、光伏预报误差、LP/凸优化/两阶段随机规划/滚动时域等建模工具"）连同两点研究不足，压成第 3 段并入 `1.1`，既避开与摘要重复，也满足韩中庚"引言须交代研究现状与技术路线"的要求。

论文封面信息（题号 C、报名号、组别、学校、三名队员）在 `论文.tex` 顶部由 `\tihao` / `\baominghao` / `\group` / `\schoolname` / `\membera~c` 等宏赋值。

### 3.2 `fonts/` 是什么

思源宋体（Source Han Serif CN）的两个字重：

| 文件 | 大小 |
|---|---|
| `SourceHanSerifCN-Regular.otf` | 11.3 MB |
| `SourceHanSerifCN-Bold.otf` | 11.8 MB |

`format.cls` 里以相对路径 `./fonts/` 引用它们。**必须保留**，删掉就编译不出中文。

### 3.3 摘要（`0.摘要.tex`）

摘要按"问题背景 → 四问分述 → 方法要点"三段组织：四问各段均以加粗的 `问题X` 起头，逐段交代**问题定位、建模方法、关键结果数字**；每段的数字与正文、`latex/求解/` 的实测输出完全一致（可回代核对）。首段点明"先计划、后兑现"的时间差这一核心约束，末段归纳"先预测、再决策、后结算"的三段式框架与残差情景随机规划两点方法考虑（不再以"其一/其二"罗列），并收束到"四问最终都化为连续变量线性规划，全局最优性可核验"——对应写作方法里"摘要须交代方法与创新点、力求可核验"的要求。全篇 CJK 786 字（已较整改前压缩 458 字，与历年优秀论文摘要篇幅相当），恰好排在第 1 页。

`\keywords{}` 五词：微网；储能调度；线性规划；滚动时域优化；光伏预报。

### 3.4 AI 使用声明（`9.AI说明.tex`）

论文含独立的 `\section*{AI工具使用声明}`，声明本队使用 AI 工具于代码编写与调试、数据处理辅助实现与文字润色，详细使用情况见支撑材料。对应的自查工具是 `C题/数学建模论文AI痕迹自动检测与诊断提示词.docx`，其文本摘录见 `C题/txt/ai_detect.txt`。

### 3.5 附录（`11.附录.tex`）

- **附录 A**：程序与结果文件说明表（哪个脚本生成哪个文件、图共 28 幅 + 检验 1 幅）。
- **附录 B**：`\lstinputlisting` 内嵌 `求解/` 下全部程序源码（`_models.py`、`_common.py`、四个 `问题X.py`、`稳健性检验.py`）。

## 四、求解程序

### 4.1 运行

```bash
# 在仓库根目录下执行
python "latex/求解/问题一/问题一.py"
python "latex/求解/问题二/问题二.py"
python "latex/求解/问题三/问题三.py"
python "latex/求解/问题四/问题四.py"
python "latex/求解/稳健性检验.py"
```

依赖：`pip install pandas numpy scipy openpyxl matplotlib`

### 4.2 数据是怎么找到的（不写死路径）

`latex/求解/_common.py` 的 `_find_data_dir()` 与 `latex/求解/_models.py` 的 `_data_dir()` 会从脚本所在目录出发，逐级向上、以及向上一级目录的各子目录里搜索含 `附件1.xlsx` 的 `附件/` 或 `数据/` 目录，取第一个命中者。当前仓库里命中 `C题/附件/`。这样把 `latex/` 移个位置、或换台机器，程序都不用改。

绘图时 `_common.py` 会在 `求解/` 下生成一个 `_fonts_ready` 哨兵文件来缓存中文字体索引；它可随时删除，下次运行自动重建（已 gitignore）。

### 4.4 模型是怎么验的

- **约束残差**：解出来后回代所有约束，功率平衡残差 1.36×10⁻¹²，容量与功率越界 0 次。
- **算法交叉验证**：Q1 用动态规划（ΔE = 20 kWh 网格）独立复算，35222.69 元 vs LP 35126.95 元，偏差 +0.27%，说明 LP 结果不是求解器假象。
- **预测模型回测**：以 1 月 24222 个 10 分钟样本训练并回测，负载 MAE 130.24 kW、光伏 MAE 150.94 kW（相对标准差约 4.50% / 9.95%）。
- **数据摄动**：对负载与光伏加 σ=5%、σ=10% 高斯噪声各重算多次，三段式下购电费均值分别约 15472366.63 元、17567357.05 元（较基准 +7.5% / +22.1%），说明紧急购电费随预报误差显著抬升。
- **无储能对照**：去掉储能后 Q1 涨到 48052.05 元、Q2 涨到 16951241.92 元，反证储能套利的贡献（分别省 26.90%、15.15%）。
- **口径对照**：把"预报展开口径"从线性插值换成阶梯保持，总费用从 14337999.15 元变成 17948773.82 元——口径本身的影响比参数扰动大得多，所以论文单独交代了这条。

## 五、Word 版论文（辅助对比）

`2026数学建模国赛论文.docx` 是同一道题、同一套模型的**单文档 Word 排版版本**，与 `latex/` 下的多文件版同题不同编排，便于对照阅读与投稿备用。

- **改 Word 版 = 改脚本后重跑**：`python make_paper.py` 会重新生成 `2026数学建模国赛论文.docx`（含程序附录）。不要手动编辑 docx，否则下次生成会被覆盖。
- 配套的参考文献文档：`python make_refs.py` → `C题/thesis/参考文献.docx`。
- 它对应的求解程序在 `C题/code/`，与 `latex/求解/` 是**两套独立实现**：建模思路一致，但紧急购电的核算细节不同，因此个别数字不同（例如该套算出的 Q3 为 17000834.39 元，而 `latex/` 版为 14337999.15 元）。**论文里引用数字请以所用版本为准，不要跨版本混引。**
- Word 版的插图由 `C题/pic/qic1~qic4.py` 生成，运行日志留在 `C题/结果/*_log.txt`。

```bash
# Word 版复现
python "C题/code/q1.py" && python "C题/code/q2.py" && python "C题/code/q3.py" && python "C题/code/q4.py"
python "C题/code/q5_sensitivity.py"   # 容量/效率/预报偏差灵敏度
python "C题/code/sens_r1r3.py"        # Q1、Q3 关键量复算
python "C题/code/q4_corr.py"          # 电价 vs 购电量/购电费相关系数
python make_paper.py && python make_refs.py
```

> 注意：`C题/code/` 的程序在 `C题/` 根目录生成工作副本（`result*.xlsx`、`q*_log.txt`），这些已被 gitignore；提交版在 `C题/结果/` 与 `C题/附件/附件5/`。
